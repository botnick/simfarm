# The style these are drawn to

Supplied by the project owner, from their own work, as the look this game's art
should share: a dark brown outline rather than a black one, gradient fills with
real volume, glossy highlights, and a warm rich palette. Handed to the drawing
model as a reference so the set holds together.

Not the original Flash game's look, and deliberately so — that art belongs to
somebody else, and this is both better and unmistakably its own.
