# Tokpla — Art Style Guide

อิงภาพ reference ที่ใช้ตั้งต้น (สไตล์ Zoo Sound Land / doodle การ์ตูน): top-down มุมเฉียงเล็กน้อย
ตัวการ์ตูนหัวโต เส้นขอบหนา สีแบนอบอุ่น

ภาพ ref ที่ผู้ใช้ส่ง (3 ภาพ): บ่อทะเลทราย+สัตว์ล้อมบ่อ, หมู่บ้านป่าเขียว+กองไฟ+บ้านไม้,
ชายหาด+สะพานไม้ตกปลา+เรือประมง 2 ลำ+ซากเรือจม — จุดร่วม: หมึกยักษ์ใส่หมวก (มาสคอต),
เหรียญตกกระจายบนพื้น, ตัวละครผู้เล่นมีผม/เสื้อผ้าชัด, UI ปุ่มกลมขาวโปร่งมุมจอ

## กติกาหลักของสไตล์

1. **เส้นขอบหนาสีน้ำตาลเข้ม** `#4a3222` — ทุก object (ไม่ใช่ดำสนิท จะแข็งไป)
   - ตัวละคร/ไอเทมใหญ่: stroke 5 หน่วยต่อ viewBox ~100px
   - รายละเอียดเล็ก (ตา ปาก): 3–4
2. **สีแบน ไม่มี gradient** — เงาใช้สีเดียวกันเฉดเข้มลง วางเป็นรูปทรงทึบ (เช่น น้ำลึก = วงรีเข้มกลางบ่อ)
3. **รูปทรงกลมป้อม** — หัวโตกว่าตัว, ต้นไม้เป็นก้อนเมฆ, ไม่มีมุมแหลม (rx ทุก rect)
4. **ตาจุดดำ + แก้มชมพู + ยิ้มเส้นโค้ง** — สูตรหน้าตัวละคร/สัตว์ทุกตัว
5. **สัดส่วนตัวละคร:** หัว ~55% ของความสูง (ดู `character.svg`)
6. **แมพต้องแน่น ไม่มีที่โล่งเปล่า** (บทเรียนจาก ref Zoo Sound Land) — ทุกระยะ ~250px ต้องมี prop อย่างน้อย 1 ชิ้น (ต้นไม้/พุ่ม/หิน/ดอกไม้/ตอไม้) + ทางเดินดินเชื่อมจุดสำคัญ ให้แมพดู "มีคนอยู่"

## สี Rarity (UI)

common `#9ca3af` · uncommon `#22c55e` · rare `#3b82f6` · epic `#a855f7` · legendary `#f59e0b` · mythic `#ec4899`

## UI Style

- ปุ่ม: มุมโค้งเต็ม (rounded-full), ขอบ 4px `#4a3222`, เงาแบบแบน `0 6px 0 #4a3222` กดแล้วยุบ
- แผง/การ์ด: พื้นครีม `#f7e7c5` ขอบหนา มุมโค้งใหญ่
- ฟอนต์หนา (black/bold) ตลอด — เข้ากับเส้นหนาของภาพ

## Pipeline Assets

- ตอนนี้: SVG placeholder ใน `public/assets/` (วาดตามกติกาข้างบน) — Phaser โหลดด้วย `this.load.svg()`
- ต่อไป: แทนด้วย sprite sheet PNG (ตัวละคร 4 ทิศ เดิน 4 เฟรม) — gen ด้วย AI จากกติกา+palette นี้ หรือซื้อ pack จาก itch.io แล้วปรับสี
- ปลา: ภาพนิ่งตัวละ 1 รูปพอ (โชว์ตอนจับได้ + ใน Fishdex) — ตาจุด แก้มชมพู ปากยิ้ม ตามสูตรเดียวกัน
- prompt ตั้งต้นสำหรับ gen ภาพ: *"cute doodle cartoon game asset, thick dark-brown outline (#4a3222), flat warm colors, round chubby shapes, dot eyes, pink cheeks, top-down slightly angled view, plain background"*
